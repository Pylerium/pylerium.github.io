# Pylerium Studio

Pylerium Studio is the home of software made by the independent Pylerium Studio: desktop apps, browser extensions, Android TV apps, and tools for creators and power users.

Visit the studio at <https://pylerium.github.io/>.

This repository contains the source for the Pylerium Studio website published at that address. It showcases multiple products from the studio, including pagePackage, Pylerium Manager, Pylerium Studio, and other apps. pagePackage is one product in the catalog; it is not the identity of this repository or the studio.
