Pylerium Studio

Public beta

A local developer workbench to build, run, inspect and showcase your projects.

Overview

Pylerium Studio combines Python execution, a Devcord project explorer, opt-in plugins, model tools, a 3D Scene Studio and a video editor in one workspace. Import a folder or ZIP, explore and edit code, run Python scripts, Flask apps or HTML pages with a live preview, and turn your work into showcases and YouTube Shorts.

Video

Highlights

  • Workshop and Devcord: import folders, ZIPs or files, then explore code, dependencies and media
  • Run Python scripts, packages, Flask apps and standalone HTML pages with a live preview
  • Scene Studio with music-reactive visuals, particles and recording
  • Built-in video editor for showcases and YouTube Shorts
  • Optional phone access over your local network with a QR code
